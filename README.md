# Nayroz Portfolio Website

A full-stack personal portfolio website built to showcase my projects, certifications, professional references, technical skills, soft skills, and activities.

The website also includes a secure admin dashboard that allows portfolio content to be managed dynamically without modifying the source code.

## 🌐 Live Demo

The website is currently deployed online using SmarterASP.NET hosting.

**Live Website:**  
https://nayrozportfolio-001-site1.gtempurl.com

## 👩‍💻 About the Project

This portfolio was developed as a full-stack web application using ASP.NET Core Razor Pages.

The public website presents my academic background, experience, projects, certifications, references, skills, and activities.

A protected admin dashboard allows authorized administration of the portfolio content through the website.

## ✨ Features

- Responsive portfolio design
- Projects showcase
- Dynamic certifications management
- Dynamic professional references
- Technical skills management
- Soft skills management
- Activities management
- Contact form with database storage
- Admin dashboard
- Secure admin authentication
- Add, edit, view, and delete portfolio content
- Certificate and reference file uploads
- CV download
- LinkedIn, GitHub, and email links
- Responsive design for desktop, tablet, and mobile

## 🔐 Admin Dashboard

The website contains a protected administration area for managing portfolio content.

The administrator can manage:

- Messages
- Certifications
- References
- Technical skills
- Soft skills
- Activities

Admin pages are protected using ASP.NET Core Identity and authorization.

> Admin credentials are private and are not included in this repository.

## 📬 Contact System

Visitors can send messages through the Contact Me page.

Messages are stored in the SQL Server database and can be viewed from the protected Admin Dashboard.
